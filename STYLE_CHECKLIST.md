# House-Style Verification Checklist

Use this after every generated deck. Open in **desktop PowerPoint** (not LibreOffice).

## Fonts

- [ ] Titles use **Space Grotesk Bold** (~33pt)
- [ ] Subtitles use **Space Grotesk** (~22pt)
- [ ] Body text uses **Raleway** or **Space Grotesk** (15-24pt bold)
- [ ] Sub-bullets use **Raleway** regular (18-20pt)
- [ ] No fallback fonts visible (Arial, Calibri, etc.)

## Colors

- [ ] Primary text: dark blue `#0D006A`
- [ ] Accent/emphasis: orange `#F59235`
- [ ] Subtitle accent: red `#F04E5B`
- [ ] No more than 3 base colors per slide
- [ ] Light backgrounds use dark/hard highlight colors
- [ ] Dark backgrounds use pastel highlight colors

## Layout & Branding

- [ ] Maverx logo present and correctly positioned
- [ ] Content stays within safe area (respects margins)
- [ ] No content in no-go areas (edges/corners)
- [ ] No blank slides
- [ ] No placeholder text ("Click to add content")
- [ ] No bullet points on first line of text (style guide rule)

## Structure (didactic arc)

- [ ] Pre-training slides: about session, timetable, agenda
- [ ] Per topic: introduction -> example -> exercise
- [ ] Wrap-up: reflection, key takeaways, what's next

## Speaker Notes (every slide)

- [ ] **Aim** -- one clear sentence on purpose
- [ ] **Time** -- short estimate
- [ ] **Instructions** -- conversational, trainer-ready, step by step
- [ ] **Reflective question** -- discussion point that must land
- [ ] **Debrief** -- one punchy closing line

## File Integrity

- [ ] No repair prompt on open in PowerPoint
- [ ] Every title and body is editable text (not images)
- [ ] Tables are real tables (click into a cell)
- [ ] Fonts and colors intact after save/reopen
